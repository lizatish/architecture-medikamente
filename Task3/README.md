# Задание 3. Оценка Data Encryption at Rest and In Transit

# Решение

### Общее решение:

1) Интегрировать платформу для автоматизированного контроля за данными (OneTrust)
2) Настроить сбор метрик по доступам к данным каждого сервиса, а также их отображение и алертинг в случае возникновения
   внештатных ситуаций (Grafana, Prometheus)
3) В качестве шифрования данных в БД использовать AES-шифрования, ключи шифрования хранить в независимом месте, например
   в VAULT (Vault)
4) Установить SIEM-систему для мониторинга и анализ событий безопасности (Splunk)
5) Установить антивирусную программу на все компьютеры и сервера (Касперский)
